# G2NRinventory

Инвентарь героя для Gothic II «Ночь Ворона» с Union. Открывается штатной клавишей инвентаря и располагается справа. Во вкладке «Последнее» предметы идут от свежих к старым. Пополнение существующей стопки поднимает предмет наверх. Во вкладках «Все» и «Оружие» оружие упорядочено по базовому урону от большего к меньшему.

У каждой категории своя иконка. Наведите на неё курсор, чтобы увидеть название. Еда и зелья находятся в отдельных вкладках. До выхода из игры инвентарь запоминает последнюю вкладку и позицию прокрутки на ней.

Наведите курсор на предмет, чтобы увидеть свойства. Одно нажатие ЛКМ или Enter передаёт игре команду использования. Стрелки перемещают выбор между ячейками, Tab меняет категорию. Колесо прокручивает сетку. Если подсказка длинная, Shift + колесо прокручивает её текст. Esc и правая кнопка закрывают окно.

Замок обозначает экипировку, для которой не хватает характеристик или круга магии. Золотая книга отмечает непрочитанные документы. После прочтения значок книги исчезает, а статус отображается в подсказке. Отметки чтения сохраняются вместе с игрой отдельно для каждого сохранения. Зелёная галочка в верхнем левом углу отмечает надетые предметы. Бронзовый ромб с восклицательным знаком в нижнем левом углу обозначает квестовый предмет по флагу игры `ITEM_MISSION`. Эти значки видны и при торговле.

Shift + ЛКМ переносит предмет во вкладку «На продажу». Там тот же жест возвращает его в обычные вкладки. Для стопки можно выбрать количество ползунком или нажать на число над ним и ввести количество с клавиатуры. Enter подтверждает перенос, Esc отменяет. Отложенная часть исчезает из обычных вкладок, а остаток доступен как прежде. Надетые предметы можно отложить после снятия. Список хранится в сохранении.

## Хотбар F1–F10

Хотбар расположен внизу по центру экрана и виден в игре и при открытом инвентаре. Чтобы назначить слот, откройте инвентарь, зажмите ЛКМ на предмете и отпустите над нужным слотом. Новый предмет заменяет назначение слота. ПКМ по слоту при открытом инвентаре очищает его. Короткий клик по предмету использует его при отпускании кнопки.

В игре клавиши F1–F10 используют назначенные предметы или надевают экипировку. Через F1–F10 обычная еда и зелья используются сразу, даже с оружием в руках. В окне инвентаря клик и Enter запускают обычную анимацию. У предмета запускается его скрипт, поэтому бонусы и счётчики сохраняют правила игры или мода. Боеприпасы и другие предметы без собственного действия можно закрепить, чтобы видеть их запас. Назначения сохраняются отдельно для каждого сохранения. Если предмет закончился, назначение сохраняется.

## Торговля

При разговоре с торговцем открывается окно с его товарами слева и вещами героя справа. Категории каждой стороны переключаются независимо. У героя также доступны вкладки «Последнее» и «На продажу». Наведение показывает свойства предмета и цену за штуку. ЛКМ открывает подтверждение сделки. Для стопок количество можно выбрать ползунком или ввести с клавиатуры. Колесо прокручивает панель под курсором, Tab переключает панели, Enter подтверждает, Esc отменяет или закрывает окно.

Зелёная стрелка на товаре отмечает улучшение относительно экипировки героя. Для оружия сравнивается базовый урон с экипированным оружием своей группы, ближней или дальней. Для доспеха сравнивается среднее по всем восьми защитам движка, включая нулевые значения. Сравнение использует экипированный предмет в соответствующем слоте.

Во вкладке «На продажу» можно выбрать отдельную вещь. Кнопка «Продать отложенное» показывает количество доступных к продаже вещей и итоговую сумму для всего списка. После подтверждения игра проводит обмен по ценам торговца. Надетые вещи защищены от продажи. Флаг `ITEM_MISSION` используется плагином только для значка и подсказки. Плагин убирает из списка только проданное.

Сундуки и обыск открываются в штатных окнах игры. Для проверки установите только один плагин, который заменяет инвентарь.

## Установка

Распакуйте артефакт `G2NRinventory` из [GitHub Actions](https://github.com/piratvasyamorexod-alt/G2NRinventory/actions) и положите `G2NRinventory.vdf` в `Gothic II\Data\Plugins`. Перезапустите игру.

Для самостоятельной сборки запустите `Build-Windows.ps1` с Git, CMake и Visual Studio 2022 с инструментами C++ для Win32.
