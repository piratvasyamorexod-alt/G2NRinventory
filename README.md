# G2NRinventory

Инвентарь героя для Gothic II «Ночь Ворона» с Union. Открывается штатной клавишей инвентаря. Предметы разложены по категориям. Оружие упорядочено по базовому урону от большего к меньшему.

Наведите курсор на предмет. Подсказка со свойствами появится рядом с курсором и исчезнет, как только он покинет ячейку. Щелчок выбирает предмет, двойной щелчок или Enter передаёт игре команду использования. Стрелки перемещают выбор между ячейками, Tab меняет категорию. Колесо прокручивает сетку. Если подсказка длинная, Shift + колесо прокручивает её текст. Esc и правая кнопка закрывают окно.

Торговля, сундуки и обыск используют штатные окна игры. Для проверки установите только один плагин, который заменяет инвентарь.

## Установка

Распакуйте артефакт `G2NRinventory` из [GitHub Actions](https://github.com/piratvasyamorexod-alt/G2NRinventory/actions) и положите `G2NRinventory.vdf` в `Gothic II\Data\Plugins`. Перезапустите игру.

Для самостоятельной сборки запустите `Build-Windows.ps1` с Git, CMake и Visual Studio 2022 с инструментами C++ для Win32.
